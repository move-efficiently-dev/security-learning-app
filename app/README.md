# app/

学習アプリ本体。

## 試作版 v0.1（2026-11-21）

`index.html` の1ファイルで動く試作版。ブラウザで開くだけで動作する（サーバー不要）。

実装済み（要件定義書 7.1 の試作範囲）:
- 受講者登録（氏名・部署、複数登録と切替）
- コース受講：4テーマ（パスワード／怪しいメール／多要素認証／バックアップ）、各テーマに実践チェックリスト表示
- 確認テスト：問題バンク（4テーマ×5問＝20問）からランダム出題（問題・選択肢ともシャッフル）、合格ライン正答率80%
- 無料体験テスト：全テーマから6問をランダム出題（記録なし）
- 結果表示：正誤と解説、間違えた問題だけの復習モード
- 記録・集計：受講者×テーマの完了マトリクス、テーマ別正答率、受講記録のCSVダウンロード
- リマインド：未修了のある受講者の一覧表示
- セキュリティ情報：公的機関（IPA／JPCERT/CC／JVN）へのリンクと分類軸の表示（自動取得は本番）

試作版の割り切り:
- データ保存はブラウザの localStorage のみ（端末をまたがない、証跡としての改ざん耐性なし）
- 本番ではサーバー側の記録・権限管理・自動リマインド・課金に置き換える

動作確認: JavaScript構文チェックと教材データ検証（4コース・20問・正解範囲）まで実施済み。
