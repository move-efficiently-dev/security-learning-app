# 仕事とITの研究所 学習アプリ（仮称）

中小企業向けセキュリティ教育サービス：教材配信、問題バンクからのランダム出題、受講記録・集計・達成度確認、リマインド、セキュリティ情報のアグリゲーションを提供するウェブアプリ。

## 現在のステータス
要件定義フェーズ（ドラフト v0.1）。開発は要件の確定後に開始する。

## ドキュメント
- アプリ要件定義書：docs/requirements-app.md
- ウェブサイト要件定義書：docs/requirements-website.md
- 調査資料：docs/research/（ISO/IEC 27001・27002、IPAガイドライン、アグリゲーション情報源）

## コードの確認方法（Cursor）
このリポジトリを Cursor で開くと、そのままコードとドキュメントを確認できます。
- GitHub から clone して開く、または Cursor の「Clone Repo」からこのリポジトリを指定する。
- アプリ本体のコードは app/ 配下に構築する。

## 構成
- docs/ … 要件定義書と調査資料
- app/ … アプリ本体（試作フェーズで構築）
