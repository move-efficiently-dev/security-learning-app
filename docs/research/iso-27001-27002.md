# 公式要件項目リスト（ISO/IEC 27001・27002／JIS Q 27001・27002）

調査日：2026-11-21。要点は規格本文の要約（長文引用なし）。正式引用時は JIS Q 27001:2023／JIS Q 27002:2024 本文で最終確認すること。

## 1. 本体要求事項（箇条7「支援」）

### 7.2 力量
- 要点：組織は (a) 必要な力量の決定、(b) 教育・訓練・経験に基づく力量の確保、(c) 必要な力量を身に付ける処置と、その処置の有効性の評価、(d) 力量の証拠として文書化した情報の保持、を行う。
- 含意：受講者ごとに「誰が・いつ・どの教材を・どの結果で修了したか」を記録保持し、審査時に提示できる形（受講記録一覧・修了証・CSV出力）で提供。理解度テストは「処置の有効性評価」の支援機能。
- 出典：JIS Q 27001 箇条7.2／ISO https://www.iso.org/standard/27001

### 7.3 認識
- 要点：組織の管理下で働く人は (a) 情報セキュリティ方針、(b) ISMSの有効性に対する自らの貢献（便益を含む）、(c) ISMS要求事項に適合しないことの意味、を認識していること。対象は派遣・委託を含む。
- 含意：教材は知識だけでなく「顧客の方針」「自分の役割と貢献」「違反時の影響」を扱う構成に。顧客組織の方針・ルールを差し込めるカスタマイズ枠があると適合支援になる。

## 2. 附属書A 6.3 と 27002 の実施の手引

### A 6.3 情報セキュリティの意識向上、教育及び訓練
- 要点：要員及び関連する利害関係者は、職務に関連する適切な意識向上・教育・訓練を受け、方針・テーマ別方針・手順について定期的な更新情報を受けること。目的は要員が自らのセキュリティ責任を認識し果たせるようにすること。
- 含意：一回限りでない設計（定期配信・年度更新・再受講）。役割別の粒度。教材の改訂・差し替えと配信履歴の管理。

### 27002手引① プログラムとしての整備
- 要点：教育は単発行事でなく、方針・手順・保護すべき情報・導入済み管理策を踏まえた「プログラム」として確立。
- 含意：年間教育計画に組み込めるカリキュラム体系（テーマ一覧・対象者・実施時期）と、顧客の教育計画書に転記できる情報の提供。

### 27002手引② 実施のタイミングと周期性
- 要点：教育は定期的に。初回は新規採用者と、要求が大きく異なる職務へ異動した者が対象。方針変更やインシデントの教訓も内容に反映。
- 含意：入社・異動時の割り当て自動化、未受講者へのリマインド、インシデント・新脅威に応じた臨時テーマの追加配信。

### 27002手引③ 理解度の評価と有効性確認
- 要点：各教育活動の終了時に受講者の理解度を評価し、知識伝達とプログラム自体の有効性を確認。
- 含意：確認テスト（ランダム出題・合格基準・再受験）、個人別・組織別の達成度（受講率・平均点・再教育状況）の集計・可視化。本サービスの集計機能の公式根拠。

### 27002手引④ 意識向上プログラムに含める内容
- 要点：①経営層のコミットメント ②方針・基準・法令・契約等のルールと義務の周知と遵守 ③自らの作為・不作為に対する個人の責任 ④基本的な手順（事象の報告＝6.8、パスワード管理等） ⑤助言・資料を得るための連絡先とリソース。
- 含意：問題バンク・教材のテーマ分類はこの5領域をカバー。報告先・相談先など顧客固有情報を教材に差し込める機能が望ましい。

### 27002手引⑤ 伝達チャネルと技術要員向け訓練
- 要点：伝達手段はウェブサイト、eラーニング、説明会、ニュースレター等の多様なチャネル。技術要員にはシステムのセキュリティ構成・維持のための訓練計画と最新知識の維持。
- 含意：動画・記事・クイズ等の複数形式で同一テーマを提供（現行の動画／note／問題集の連携と整合）。情シス向け上級テーマ枠。

## 3. 関連する人的管理策（6.x）
- 6.1 選考：役割・リスクに応じた教育レベルの出し分けの考え方と連動。受講者の属性管理（職種・権限）の設計根拠。
- 6.2 雇用条件：契約でセキュリティ責任を明記。入社時教育に「雇用条件としての責任・守秘義務」を含め、受講確認の同意記録と組み合わせると証跡性が高い。
- 6.4 懲戒手続：違反への手続を定め周知。手引では「十分な教育を受けていたか」も考慮要素。受講記録の正確性・改ざん防止・長期保持が必要。
- 6.5 雇用の終了又は変更後の責任：退職・異動時のアカウント無効化などライフサイクル管理支援。
- 6.6 秘密保持契約：入社時教育と誓約取得の一体運用。サービス提供者側の守秘・個人情報保護体制も要件に含める。
- 6.7 リモートワーク：テレワーク教材化の根拠（現行シリーズ「テレワークの注意」に対応）。
- 6.8 情報セキュリティ事象の報告：要員が事象を速やかに報告できる仕組みと、その認識。教材の必須テーマに「報告」（何を・どこへ・どう報告するか）。顧客固有の報告先の差し込み。

## 4. 総括：サービス側の必須機能6点
1. 受講記録の保持と証拠出力（7.2(d)）：受講履歴、修了証・一覧出力
2. 理解度評価（7.2(c)、手引③）：確認テスト、合否、再受講、達成度集計
3. 定期性とライフサイクル対応（6.3、手引②）：定期配信、入社・異動時の割り当て、未受講リマインド
4. 職務適合性（6.3）：役割別カリキュラム、技術者向け上級テーマ
5. 内容の5領域カバーと顧客固有情報の差し込み（手引④、7.3）
6. 教材の定期見直し（6.3「定期的な更新情報」）：改訂と版管理
