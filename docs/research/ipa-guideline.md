# 公式ガイド項目リスト（IPA「中小企業の情報セキュリティ対策ガイドライン」第4.0版ほか）

調査日：2026-11-21。出典は主にIPA公式 https://www.ipa.go.jp/security/guide/sme/about.html （第4.0版、2026-03-27公開）。

## ガイドライン本体（教育関連）
- 1-1 経営者の役割（第1部）：3原則と重要7項目。取組2＝予算・人材の確保（外部サービスの利用も検討対象）。取組3＝対策を社内ルールとして文書化させ、実施状況を定期的に報告させて進捗・効果を把握。取組5＝緊急時体制の整備後に模擬訓練。取組7＝最新動向の収集と共有。→ サービス含意：経営者・責任者が実施状況の報告を受けられる管理機能（進捗レポート出力）。
- 1-2 情報セキュリティ6か条 No.6「脅威や攻撃の手口を知ろう」（第2部STEP1）：教育・啓発に相当。他5項はOS・ソフト最新化、ウイルス対策、パスワード強化、共有設定見直し、バックアップ。→ 入門コースの最小テーマセットの軸。No.6は最新手口を扱うため教材の継続更新が前提。
- 1-3 自社診断25項目（STEP2／付録3）：Part1基本的対策10問／Part2従業員としての対策9問／Part3組織としての対策6問。第20問「従業員に教育や注意喚起を行っていますか？」、第25問「対策をルール化し従業員に明示していますか？」。採点100点満点、部署ごとに記入し責任者が集計する運用。→ テーマ分類を診断項目と対応づけると「弱い項目を教材で補う」動線が作れる。集計は部署単位。
- 1-4 ハンドブックの全従業員配付（STEP2／付録4）：決めた対策はハンドブック（ひな形）に落とし込み全従業員に配付、説明機会を設けて周知。→ 教材は自社ルールと結びつく形（自社ルール掲載欄、配付＝配信の記録）が望ましい。
- 1-5 体制（STEP3）：体制図に「教育責任者」が独立役職として位置づく。役割・責任は文書化。→ アプリの権限設計は「経営者／教育責任者（管理者）／部門責任者／従業員」が前提。
- 1-6 ルール化と教育の連動（STEP3）：法令・契約の要求は社内ルールへ反映し「教育と周知まで」行う。守秘義務は文書化と説明で意識付け、機密を扱う役職員には誓約書の提出と保管・更新・回収の管理。→ 「ルール説明＋理解確認＋誓約」をデジタルで完結させ記録を保管する機能。
- 1-7 意識向上とトレーニング（STEP3）★中核：対象は経営陣を含むすべての役職員・社外要員。意識向上教育は「定期的に」実施。「実施記録を保管する」ことが明示され、「理解度と受講状況の評価結果を踏まえて改善する」まで要求（実施→記録→評価→改善のサイクル）。→ 受講管理・理解度集計・達成度可視化・弱点テーマ抽出が必須機能。経営者層も含むコース設計。
- 1-8 インシデント対応の教育・訓練（STEP3）：定められた頻度で実施し、実施状況の記録・保管を規程に定める。内容の定期見直し。事故事例と対応策の定期共有、再発防止策として「教育の徹底」。→ インシデント対応は独立テーマ＋演習型が望ましい。教材の定期見直しは提供側の運用要件。時事テーマのプッシュ配信の根拠。
- 1-9 点検と証跡（STEP3）：点検方法「閲覧（レビュー）」は「対策を実行した証拠となるもの」を確認する方法。点検結果は経営者に報告。→ 受講記録・テスト結果は証拠として提示できる形式（改ざんされにくい保管、期間指定の出力・印刷）。
- 1-10 テレワーク（STEP4）：ルールを定め教育・啓発で理解・遵守させる。相談・報告の連絡先と対応手順書の整備。→ オンライン教材自体が周知手段。テーマ軸に「テレワーク」。
- 1-11 外部教育サービス（STEP4）：類型「情報セキュリティ教育サービス」＝知識・スキルの習得、対策の解説や周知を支援するサービス。社内人材不足時に活用が有用。品質の目安は経産省「情報セキュリティサービス基準」適合リスト（IPA公開）。→ サービス範囲は「習得支援」と「解説・周知支援」の両面で定義。
- 1-12 事故事例（第1部）：教育は単独でなく「ルール整備とセット」で位置づけ。

## IPAの教材・仕組み（設計の参考）
- 3-1 ポイント学習「5分でできる！情報セキュリティポイント学習」：1テーマ5分、日常の一場面を疑似体験する形式。コースは対象者別（経営者・管理者向け6テーマ／従業員向け4テーマ／自社診断25問対応25テーマ／学校指導者向け6テーマ）。各テーマ末尾に確認テスト。現在はPDF版のみ（オンライン版終了）。→ 「1テーマ短時間完結＋確認テスト」がIPA教材の標準形。分類軸は「対象者」×「診断項目対応」。受講管理まで担うオンラインサービスの差別化余地。
- 3-2 映像で知る情報セキュリティ：YouTube「IPA Channel」で社内研修に利用可。分類は対象・テーマ別（基本、中小企業、テレワーク、内部不正・情報漏えい、新入社員、BEC、ランサムウェア、SNS等）。
- 3-3 華麗なる情報セキュリティ対策：従業員が日常行うべき8つの対策を2分動画×8話（修正プログラム適用、セキュリティソフトと定義ファイル最新化、パスワード、不審なメール、USBメモリ、機器接続ルール、ソフトインストール時の注意、画面ロック）。→ 従業員向けカリキュラムの骨格に使える。
- 3-4 情報セキュリティ10大脅威：毎年公表（組織編・個人編、解説書と研修用スライド）。2026年版組織編はランサムウェア、サプライチェーン攻撃に続き「AIの利用をめぐるサイバーリスク」が上位。→ 教材テーマは年次見直しが前提。運用要件（コンテンツ保守）の根拠。
- 3-5 講習能力養成セミナー：教育担当者向け。Chapter 1「教育計画の立て方」等。利用企業の教育担当者は専門家でないことが前提。→ 年間計画のひな形など計画支援要素。
- 3-6 SECURITY ACTION：自己宣言制度。一つ星＝6か条、二つ星＝自社診断＋基本方針の策定・公開。→ 達成度表示や修了認定の設計と相性。
- 3-7 ここからセキュリティ！：定常的な情報収集先のポータル。収集情報は会議・メール・社内ポータルで共有推奨。→ 注意喚起の配信・共有の導線。

## 他の公式ガイド
- 4-1 サイバーセキュリティ経営ガイドライン（経産省／IPA）：経営者向け。経営者層コンテンツは「指示と実施状況の把握」の観点で設計。
- 4-2 組織における内部不正防止ガイドライン（IPA）：10の観点・33項目。「内部不正」を独立テーマにする根拠。禁止事項の周知だけでなく相談・報告しやすい環境とセット。
- 4-3 JIS Q 27001:2023／JIS Q 27002:2024 がガイドライン巻末の参照規格に明記。STEP3の枠組みは規格の管理策と整合。記録項目（受講者、教材、実施日、理解度結果）を規格に耐える粒度で保持。

## 総括表（観点→根拠→読み替え）
- テーマ分類の軸：6か条／自社診断25項目／10大脅威／映像教材分類 → 「基本対策」「診断項目対応」「脅威・場面別」の複合軸
- 対象者別設計：ポイント学習のコース分け、体制図の役割 → 経営者・管理者／従業員／新入社員のコース区分と権限分離
- コンテンツ粒度：ポイント学習5分、華麗なる対策2分 → 1テーマ短時間完結＋末尾に確認テスト
- 理解度確認：確認テスト、STEP3の評価 → テーマごとのテストと集計・達成度表示は必須
- 受講管理と記録：STEP3「実施記録を保管」 → 誰が・いつ・何を・どの結果で修了したかを保持・出力
- 証跡提示：点検「閲覧＝証拠の確認」 → 期間指定出力など監査・説明に使える形式
- 実施頻度：定期的実施、頻度を定めた訓練、事故事例の定期共有 → 年次等の定期受講設定、未受講リマインド、時事テーマ配信
- 評価と改善：評価結果を踏まえて改善、内容の定期見直し → 弱点テーマ分析＋教材改訂の運用体制
- ルール連動：ハンドブック配付と説明、規程サンプル → 自社ルールと教材・受講記録のひもづけ
- 経営者報告：取組3の進捗報告、点検結果の経営者報告 → サマリーレポート機能
- 外部サービスの類型：「情報セキュリティ教育サービス」の定義 → サービス範囲は習得支援＋解説・周知支援
