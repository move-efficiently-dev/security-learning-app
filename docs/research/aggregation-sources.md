# セキュリティ情報アグリゲーション：公式情報源の収集方法と利用条件

調査日：2026-11-21。アプリ要件定義書 4.9 の前提資料。

## 1. IPA
- 発信：「重要なセキュリティ情報」（緊急対策情報・注意喚起）。更新は不定期（直近30日で6〜7件、週1件ペース）。
- RSS：あり。https://www.ipa.go.jp/security/alert-rss.rdf （旧URL系統もあるため実装時に現行URLを再確認）。
- メール配信：IPAメールニュース（「情報セキュリティ」選択可）。
- 公式埋め込み：「icat for JSON」—IPA公式の注意喚起表示サービス。HTMLタグ埋め込みで一覧をリアルタイム自動表示。会員向けウェブサイトへの設置が想定されている。表示レイアウトは固定形式。X公式アカウント @ICATalerts でも発信。
- 10大脅威：年1回（1月下旬）。解説書PDF、スライド、ハンドブック等を無償公開。
- 利用条件（公式「ウェブサイトのご利用について」 https://www.ipa.go.jp/about/riyojoken/ ）：著作権は原則IPA。出所明示を条件に引用・転載可。個別ページの条件が優先。リンクは基本自由だが、他ページ内に組み込む形のリンクは禁止。商用利用の禁止明記なし。

## 2. JPCERT/CC
- 発信：注意喚起＆緊急報告（随時、影響の大きい案件のみ）、Weekly Report（週1回）、お知らせ、ブログ。
- RSS：あり（公式 https://www.jpcert.or.jp/rss/ ）。「どなたでも自由にご使用ください」と明記。① https://www.jpcert.or.jp/rss/jpcert.rdf （注意喚起＆緊急報告の最新6件＋Weekly Report）②統合版 https://www.jpcert.or.jp/rss/jpcert-all.rdf （①＋お知らせ＋JVN新着）。
- メール配信：メーリングリストあり（https://www.jpcert.or.jp/announce.html ）。
- 利用条件：サイト全体の転載ポリシー専用ページは未確認。資料ごとに条件が異なり、例：APT対応ガイドは引用・転載・再配布に広報（pr@jpcert.or.jp）への連絡を求める。CSIRTマテリアルは「商用目的での転載および流用などの改変は固く禁止」。CC BY-SA 4.0の資料もある。
- 注意：フィードの「使用自由」と、商用アプリ内での要約・再構成表示の可否は同義ではない。公開前に広報窓口へ確認すること。

## 3. 国家サイバー統括室（旧NISC）
- 現在の発信拠点は主に cyber.go.jp（「サイバー対応特設サイト」で関係機関の注意喚起を集約掲載）。更新は不定期。
- RSS：未確認（公式フィードを確認できず）。収集はWeb巡回または公式Xの補助確認が現実的。
- 利用条件：cyber.go.jp個別の利用条件は未確認。採用前に個別確認。

## 4. その他
- JVN／JVN iPedia（IPA・JPCERT/CC共同運営）：脆弱性対策情報。RSS https://jvn.jp/rss/jvn.rdf 。新着表示用のJSツールも公式提供され「個人、法人を問わず自由に利用できる」。JVN iPediaにもデータフィードあり。JPCERT/CC統合版RSSにもJVN新着が含まれる。
- 警察庁サイバー警察局：「サイバー警察局便り」（月数回）等。トップページに新着RSSリンクあり（正確なURLは未確認）。利用条件は未確認。

## 収集設計の前提（総括）
1. 一次収集は公式フィードを正とする：IPA RSS、JPCERT/CC RSS（統合版含む）、JVN RSSの定期取得を主経路にする。フィードのない情報源（国家サイバー統括室等）はWeb巡回・公式SNSの補助確認に位置づける。
2. 表示は「見出し＋発表日時＋自前要約（短文）＋出典リンク」に限定し、全文転載は行わない。本文は出典ページへのリンクで参照させる。
3. IPAは公式埋め込み「icat for JSON」の併用を検討する（会員向けサイトへの設置が公式想定）。固定レイアウトのため、アプリ一覧UIへの統合か別枠併設かは設計判断として残す。
4. JPCERT/CCの商用利用条件は、公開前に広報（pr@jpcert.or.jp）へ確認することを前提条件とする。確認が取れるまではJPCERT/CC由来の表示も「見出し＋日時＋リンク」の最小構成に留める。
5. 政府機関サイト（国家サイバー統括室、警察庁）は利用条件を確認できたものから順次対象に加える段階的導入とする。
